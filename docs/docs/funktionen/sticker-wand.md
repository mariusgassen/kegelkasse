# Sticker-Wand

Wir kleben auf Reisen Sticker. Auf der **Sticker-Wand** (Verein → 🏷️ Sticker) postet jedes Mitglied ein Foto davon, samt Ort. Alle sehen die Beiträge im **Feed** und die Orte auf einer **Weltkarte**.

## Sticker posten

Tippe auf **+ Sticker posten** und gib an:

- **Foto** (Pflicht).
- **Ort** (Pflicht), z. B. „Lissabon, Portugal". Das ist der Name, der im Feed und in der Karte erscheint.
- **Position auf der Karte** (Pflicht): Tippe auf die Karte, um den Pin zu setzen, oder auf **Meinen Standort verwenden**. Enthält das Foto GPS-Daten (JPEG von der Kamera), wird der Pin automatisch dort gesetzt; ein von dir gesetzter Pin hat immer Vorrang.
- **Geklebt am** und **Beschreibung** (optional).

Bearbeiten und Löschen können der Autor und Admins über das ⋮-Menü der Karte.

## Feed und Karte

- **Feed**: neueste zuerst (nach dem Tag, an dem der Sticker geklebt wurde). Fotos öffnen per Tipp im Vollbild; ❤️ und Kommentare funktionieren wie bei Neuigkeiten.
- **Karte**: ein Pin pro Ort, mehrere Sticker nahe beieinander werden mit einer Zahl zusammengefasst. Ein Tipp auf den Pin zeigt den Ort, **Beitrag ansehen** springt zum neuesten Post dort.

## Hinweise

- Die Karte nutzt OpenStreetMap-Kacheln und braucht eine Internetverbindung; ohne Netz erscheint ein Hinweis, der Feed funktioniert weiter.
- Es werden keine Ortsdaten an Dritte geschickt außer den Kartenkacheln, die dein Browser lädt.
